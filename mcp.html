/ install

Pick your client. Paste the config.

The MCP server runs locally via npx. No Docker. No build step. No keys to leak.

Claude Codeclaude mcp add →
Codex~/.codex/config.toml →

01 add the server
claude mcp add

In your terminal, run the one-liner. Claude Code persists the server config so it survives restarts.

shell
# add the Dataline MCP server
claude mcp add tearline npx -- -y @tearline/mcp@latest

# scope to your user (optional)
claude mcp add tearline -s user -e TEARLINE_KEY=sk_live_... \
  -- npx -y @tearline/mcp@latest
01 edit ~/.codex/config.toml
Add an mcp_servers entry

Codex reads its TOML config at startup. Drop the block in and restart the Codex session.

~/.codex/config.toml
[mcp_servers.tearline]
command = "npx"
args    = ["-y", "@tearline/mcp@latest"]

[mcp_servers.tearline.env]
TEARLINE_KEY = "sk_live_..."
01 edit .cursor/mcp.json
Add an mcpServers entry

Cursor reads MCP servers from your project root or user config. Save the JSON and reload the window.

.cursor/mcp.json
{
  "mcpServers": {
    "tearline": {
      "command": "npx",
      "args": ["-y", "@tearline/mcp@latest"],
      "env": {
        "TEARLINE_KEY": "sk_live_..."
      }
    }
  }
}
verify
$ npx @tearline/mcp@latest --version  → 0.1.0 ✓ ready

/ why mcp

Tools your agent already knows how to call.

MCP is the standard — Claude, Codex, and Cursor all read the same manifest.

  • Discover.
    Tool list, arg shapes, and descriptions are advertised at connect. Your model picks the right call.
  • Trust.
    Every response carries a confidence score and source list — not a flat number to memorize.
  • Compose.
    Chain tools across one turn — resolve intent → fetch sources → return a grounded answer.
  • Stream.
    Live updates over SSE. Watch a price, a position, a market — without polling.
