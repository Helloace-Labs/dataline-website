Intent

Describe what you need in natural language. Dataline routes, normalizes, aggregates, and returns confidence-scored data. five stages, one call.

POST /v1/intent/resolve Resolve a natural-language intent confidence ▾

Single black-box endpoint. Pass an English intent like "BTC price", "ETH funding rate", or "Polymarket odds for 2028 election". Dataline picks sources, fetches in parallel, normalizes to a unified schema, aggregates, and returns the result with a confidence score (0–1) so your agent can refuse or flag low-trust data.

Body
NameTypeRequiredDescription
intent*stringyesNatural-language intent. Max 500 chars.
venuesstring[] | nullnoRestrict routing to a venue allowlist. Defaults to global routing. Example: ["binance","hyperliquid"].
min_confidencenumbernoReject responses below this score. Range 0–1. Default 0.0.
timeout_msintegernoHard cap on total resolution time. Default 3000. Max 10000.
tracebooleannoInclude the 5-stage trace (route / normalize / aggregate). Default false.
Responses
200Resolved. Returns a TearlineResult with data, confidence, source, latency_ms, and an optional trace.
409Confidence below min_confidence. The agent should not act on this data.
422Intent could not be parsed.
504Routing exceeded timeout_ms.
cURL TypeScript Python 200 · 87 ms 
# resolve a natural-language intent
curl -X POST https://api.tearline.io/v1/intent/resolve \
  -H "Authorization: Bearer $TEARLINE_KEY" \
  -d '{
    "intent": "BTC price",
    "min_confidence": 0.9,
    "trace": true
  }'
POST /v1/intent/plan Preview the route plan without executing

Markets

Direct queries against the unified Market schema. Same shape across Binance, Coinbase, Hyperliquid, OKX, and 18 others.

GET /v1/markets/{symbol}/price Aggregated spot price confidence
GET /v1/markets/{symbol}/orderbook L2 orderbook, top N levels
GET /v1/markets/{symbol}/candles OHLCV candles, any timeframe
GET /v1/perps/{symbol}/funding Perp funding rate, all venues
GET /v1/perps/{symbol}/oi Open interest aggregated
GET /v1/markets/search Resolve a token to canonical symbols
GET /v1/markets/venues List supported venues + status

Prediction markets

Odds, events, and resolution feeds with venue parity.

GET /v1/prediction/events Active events with filters
GET /v1/prediction/event/{id} Event detail with outcomes
GET /v1/prediction/event/{id}/odds Live odds, all venues confidence
GET /v1/prediction/resolutions Recently resolved events

Act write side

Same intent surface, write side. Dataline returns a signed-tx payload; your wallet broadcasts. Funds never leave the user.

POST /v1/act/swap/quote Quote a token swap, all venues
POST /v1/act/swap/build Build an unsigned swap tx
POST /v1/act/perps/build Open / close a perp position
POST /v1/act/predict/build Place a prediction-market bet
POST /v1/act/broadcast Broadcast a signed tx (optional)

Agents

Run multi-step agents on Dataline's hosted runtime. FlowAgent for orchestration, GhostDriver for browser execution, ChatPilot for conversational surfaces.

POST /v1/agents/flow/runs Start a FlowAgent run
GET /v1/agents/flow/runs/{id} Run status + step trace
POST /v1/agents/ghost/sessions Open a browser session for long-tail dApps
POST /v1/agents/ghost/sessions/{id}/step Execute a browser step
POST /v1/agents/chat/messages Send a ChatPilot message
